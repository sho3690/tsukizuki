# 月々 — サブスクの帳簿

サブスクの月額と年額を、ひと目で確認するための小さなアプリです（リポジトリ名は tsukizuki）。
公開先: https://sho3690.github.io/tsukizuki/

- 登録内容は端末のブラウザ（localStorage）にだけ保存され、外部には送信されません
- 合計は「月あたり」「年あたり」を横に並べて表示。登録したサブスクは横にスライドするカードで並び、金額順・名前順に並び替えられます
- カードの下に「支払い周期ごと」の内訳（毎月払い・毎年払い、必要に応じて3か月ごと・半年ごと）
- 右上の歯車（設定）の「バックアップ」から、JSONとして持ち出し・復元できます
- iPhoneでは「ホーム画面に追加」でアプリのように使えます（オフライン対応）
- 見た目は ~/.claude/design-system.md（白地・細い罫線・青1色・システムフォント）に準拠。表記は日本語で統一

## 構成
- `index.html` … 画面と動作のすべて（依存ライブラリ・外部フォントなし）
- `sw.js` … オフライン用のキャッシュ（`index.html` を変えたら `VERSION` を上げる）
- `manifest.webmanifest` / `icons/` … ホーム画面追加用（`icon.svg` が角丸、`icon-square.svg` が全面塗り。PNG はこの2つから書き出し）
