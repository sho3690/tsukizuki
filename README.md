# 月々（つきづき） — サブスクの帳簿

サブスクの月額と次の支払日を、ひと目で確認するための小さなアプリです。
公開先: https://sho3690.github.io/tsukizuki/

- 登録内容は端末のブラウザ（localStorage）にだけ保存され、外部には送信されません
- 支払日を過ぎると、次の支払日に自動で進みます
- 「バックアップを保存 / 読み込む」でJSONとして持ち出し・復元できます
- iPhoneでは「ホーム画面に追加」でアプリのように使えます（オフライン対応）

## 構成
- `index.html` … 画面と動作のすべて（依存ライブラリなし）
- `sw.js` … オフライン用のキャッシュ
- `manifest.webmanifest` / `icons/` … ホーム画面追加用
